# 国开公开脚本页面适配证据

> 调研日期：2026-10-26
> 范围：只研究页面加载、活动节点定位和选择器策略；不运行脚本，不研究或复用自动学习行为。

## 结论

公开资料不足以提供可直接复制的当前版 LMS DOM 选择器。

- 一个公开油猴脚本表明浏览器内 DOM 自动化是常见路线，但源码受站点验证保护，
  无法核实其具体选择器，结论等级为“单一来源、待验证”。
- 一个公开 Python 项目采用 cookie 和 `learning-activity` 接口直接操作，属于当前
  项目明确拒绝的接口路线，不能借鉴。
- Playwright 官方生成器优先 role、text 和 test-id，并在定位不唯一时收紧 locator；
  该原则可用于本项目，但不能替代真实国开活动节点样本。

因此采用：

```text
等待 .learning-activity 出现并稳定
→ 定向录制最多 10 个活动节点
→ 从真实样本确认 ID、标题、类型和完成态
→ 离线适配 inspector
```

## 反证检查

| 主张 | 证据等级 | 反证或限制 | 处理 |
|---|---|---|---|
| `.learning-activity` 是活动容器 | 已证实 | 早期 discovery 采集时节点尚未出现 | 增加稳定等待，不更换容器选择器 |
| 真实节点有 `data-activity-id` | 已否定 | 真实运行报错显示该属性为空 | 从定向样本寻找 href 或 element id |
| 可直接复制公开脚本选择器 | 已否定 | DOM 型脚本源码不可核实；接口型脚本不是 DOM 路线 | 不复制，真实样本优先 |
| 完成态可由中文文案判断 | 待验证 | 没有可靠结构证据 | 默认 `unknown` |

## 明确排除

- 自动播放、倍速、自动下一课。
- 自动确认、防挂机处理。
- 心跳、学习时长或完成接口。
- cookie、请求头或账号信息复制。
- 自动答题、提交或发帖。
- stealth、webdriver 修改和 OS 输入。

## 采用的最小实现

1. 等待至少一个 `.learning-activity`。
2. 要求活动数量连续三次稳定。
3. 只录制活动节点及最多 60 个后代节点。
4. URL 删除 query 和 fragment。
5. 从真实样本确定 ID 提取顺序。
6. 未证明的类型或完成态记录为 `unknown`。
